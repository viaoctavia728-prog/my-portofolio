Tentang

Saya adalah mahasiswi program studi D3 Teknik Informatika di Politeknik Elektronika Negeri Surabaya (PENS) yang berfokus mendalami Backend Development dan rekayasa perangkat lunak. Ketertarikan saya berakar pada perancangan logika di balik layar—memastikan alur data berjalan efisien, terintegrasi, dan memiliki akuntabilitas yang jelas antara basis data serta antarmuka pengguna.

Dalam pengerjaan proyek, saya terbiasa membangun RESTful API yang terstruktur menggunakan Python (FastAPI) dan Express.js (Node.js), serta merancang dan mengoptimalkan basis data relasional seperti MySQL dan PostgreSQL. Untuk menjaga konsistensi lingkungan dari tahap pengujian hingga deployment, saya memanfaatkan Docker & Docker Compose pada sistem operasi Linux (Ubuntu).

Selain fokus di sisi server, saya juga memahami antarmuka web modern (HTML5, CSS3 Mobile Responsive, Tailwind CSS) serta pengalaman riset antarmuka di Figma, yang sangat mendukung kolaborasi yang solid dan komunikasi teknis lintas disiplin dengan frontend developer dan UI/UX designer.
