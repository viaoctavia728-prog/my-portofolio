Tentang Saya

Fokus pada Fondasi dan Alur Data yang Andal

Saya adalah mahasiswi program studi D3 Teknik Informatika di Politeknik Elektronika Negeri Surabaya (PENS). Minat utama saya berada pada pengembangan sisi backend, di mana saya menikmati proses perancangan logika server, optimalisasi alur data, serta memastikan sistem memiliki integritas dan akuntabilitas yang tinggi antara basis data dan antarmuka pengguna.

Dalam membangun sistem, saya terbiasa menggunakan Python dengan framework FastAPI serta Express.js (Node.js) untuk menyediakan RESTful API. Pengelolaan basis data saya lakukan menggunakan MySQL dan PostgreSQL. Untuk menjaga lingkungan kerja tetap konsisten dan siap diterapkan, saya memanfaatkan Docker serta terbiasa bekerja pada sistem operasi Linux (Ubuntu).

Sebagai keahlian pendukung, saya juga memahami dasar antarmuka web (HTML5, CSS3 responsif dengan Tailwind CSS) dan pengalaman riset antarmuka di Figma, yang mempermudah koordinasi teknis bersama pengembang frontend dan desainer produk.

SI-BANSOS JATIM (NGROWO)

Sistem Informasi Transparansi & Pelaporan Bantuan Sosial Jawa Timur

Problem & Latar Belakang:

Kurangnya transparansi dan lambatnya alur validasi dalam pencatatan serta pelaporan data penerima bantuan sosial, yang rentan menyebabkan duplikasi dan ketidakakuratan data di tingkat wilayah.

Solusi Teknis:

Mengembangkan layanan backend RESTful API terstruktur dengan integrasi database relasional dan konfigurasi containerized deployment menggunakan Docker Compose pada lingkungan Linux (Ubuntu).

Peran Saya:

Backend Developer & System Designer: Merancang skema relasional database, membuat endpoint RESTful API terstruktur dengan FastAPI, serta mengonfigurasi Docker Compose environment.

Python (FastAPI) MySQL Docker Compose RESTful API Linux (Ubuntu) Postman

  • FastAPI RESTful Endpoints with Pydantic Schema

  • Docker Compose isolated networking & volume
  • Tested with Postman & Swagger API Docs
